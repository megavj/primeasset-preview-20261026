# madaeri-site-preview-20261026 / r1 — 프라임에셋 프리미엄사업부 홈페이지 개편 시안

격리된 정적 시안입니다. **운영 사이트가 아니며**, primeasset.info 공개 페이지를 참고해 정보구조를 다시 짠 결과물입니다.
이 폴더 밖의 파일, 운영 사이트, 도메인/DNS, 인증 파일은 건드리지 않았습니다. 배포하지 않았습니다.

## 1. 구현 파일

| 경로 | 역할 |
| --- | --- |
| `index.html` | 단일 페이지. 소개 / 설계사 지원 / 교육·성장 / 자료·안내 / FAQ / 문의 여섯 섹션 |
| `assets/css/styles.css` | 모바일 우선 스타일. 외부 폰트·CDN 없음, 시스템 폰트 스택만 사용 |
| `assets/js/main.js` | 모바일 메뉴, 스크롤 스파이, FAQ 단일 열림, 해시 이동 포커스. 외부 호출·저장 없음 |
| `README.md` | 이 문서 |
| `BRIEF.md` | 입력 지시서(기존 파일, 수정하지 않음) |

이미지·폰트·서드파티 스크립트 파일은 없습니다. `index.html`을 더블클릭해 `file://`로 열어도 동작합니다.

## 2. 기능

- **정보구조**: 한 페이지에 밀집되어 있던 소개·모집·교육·규정을 6개 섹션으로 분리. 헤더 메뉴와 히어로 "차례"에서 모두 섹션 이동 가능.
- **주요 CTA**: "합류 상담 안내"(→ 문의 섹션), "설계사 지원 살펴보기"(→ 설계사 지원 섹션). 히어로, 설계사 지원, 문의에 배치.
- **모바일 메뉴**: 햄버거 버튼(`aria-expanded`, `aria-controls`). 열면 첫 링크로 포커스 이동. Esc, 바깥 클릭, 링크 선택, 탭으로 헤더 밖 이탈, 데스크톱 폭 전환 시 닫힘. 닫을 때 버튼으로 포커스 복귀.
- **FAQ**: 네이티브 `<details>/<summary>` 7개. JS 없이도 열고 닫힘. JS가 있으면 하나만 열림(`name` 속성 + 보완 스크립트).
- **스크롤 스파이**: 현재 보이는 섹션의 메뉴 항목에 `aria-current="true"`. IntersectionObserver 미지원 시 조용히 생략.
- **접근성**: skip link, `<header>/<nav>/<main>/<footer>` landmark, `aria-labelledby` 섹션, h1 → h2 → h3 순차 제목, `:focus-visible` 금색 아웃라인, 새 창 링크에 "(새 창)" 숨김 텍스트, `scroll-margin-top`으로 고정 헤더에 가려지지 않음.
- **모션**: `prefers-reduced-motion: reduce`에서 smooth scroll·전환 모두 해제. 자동재생 영상·애니메이션 없음.
- **디자인**: 이미지 없는 타이포그래피 중심 편집 디자인. 큰 세리프 헤드라인, 금색 큰 번호(01–06), 12칸 비대칭 그리드(헤드 4칸 sticky / 본문 7칸, 03 섹션은 좌우 반전), 흰색/따뜻한 중성(`#faf8f4`) + 짙은 남색(`#0f2447`) + 차분한 금색(`#a8893f`).
- **크롤러 차단**: `<meta name="robots" content="noindex, nofollow">`. 시안이 검색에 노출되지 않도록 함.

## 4. 부모(검토자)가 확인해야 할 항목

### 4-1. 아직 확정되지 않은 내용
- **운영 사이트 링크 스킴**: 모든 외부 링크가 `https://primeasset.info/` 첫 화면으로 향함. HTTPS 제공 여부와 세부 페이지(모집/교육/규정/공지) 주소는 확인하지 못했음. 확인 후 `index.html`의 `.resource` 링크 4개와 문의 버튼·footer 링크를 교체할 것.
- **교육·성장 섹션의 4갈래 분류(기초 / 상품·보장 이해 / 규정·준법 / 현장 실무)**: 운영 사이트 자료를 묶어 보여 주기 위한 **분류안**이며, 실제 과정명이 아님. 페이지에도 "분류안"으로 표기함. 운영 자료와 맞지 않으면 문구 수정 필요.
- **설계사 지원 4단계 흐름**: 실제 채용 절차가 아니라 "안내를 읽는 순서"로 서술함. 실제 절차가 공개되어 있다면 교체 가능.
- 조직 소개 문구는 BRIEF에 적힌 사실(주체·주소·공개 창구)만 사용. 설립연도·인원·실적 등은 의도적으로 비어 있음.

### 4-2. 로컬 검증 지시 (브라우저 사용은 부모 담당)
1. 폴더에서 `index.html`을 브라우저로 열기. 또는 폴더에서 다음을 실행 후 `http://localhost:8000/` 접속:
   ```
   python3 -m http.server 8000
   ```
2. **반응형**: 320 / 375 / 768 / 1024 / 1280px 폭에서 가로 스크롤이 생기지 않는지, 56em(896px) 미만에서 햄버거 메뉴, 이상에서 가로 메뉴로 바뀌는지.
3. **모바일 메뉴**: 버튼 탭 → 메뉴 열림·첫 링크 포커스 → Esc로 닫힘·버튼 포커스 복귀. 바깥 클릭·링크 클릭으로도 닫힘.
4. **섹션 이동**: 메뉴·차례·CTA 링크 클릭 시 해당 섹션이 고정 헤더 아래 가려지지 않고 보이는지. 메뉴에서 현재 섹션 밑줄(aria-current) 갱신 확인.
5. **FAQ**: 질문 클릭/Enter/Space로 열림, 다른 항목 열면 이전 항목 닫힘. JS 비활성화 상태에서도 열고 닫힘.
6. **키보드**: Tab 첫 번째 포커스에 "본문으로 바로가기" 스킵 링크 노출. 모든 링크·버튼·summary에 금색 포커스 링.
7. **reduced motion**: OS 설정 "동작 줄이기" 켠 뒤 섹션 이동이 즉시 점프하는지.
8. **네트워크**: 개발자도구 Network 탭에서 `index.html`, `styles.css`, `main.js` 세 요청만 발생하는지(외부 요청 0).
